# Coin Toss Simulator

## Description
A simple Python program that simulates tossing a coin 
and randomly displays either Heads or Tails.

## Features
- Randomly generates Heads or Tails.
- Allows users to toss the coin multiple times.
- Simple and interactive menu.
- Uses random selection for realistic coin toss results.

## Technologies Used
- Python 3

## Concepts Learned
- `random` module
- `random.choice()`
- `while` loop
- User input using `input()`
- Conditional statements (`if`)
- Loop control using `break`

## Future Improvements
- Count the total number of heads and tails.
- Display the percentage of heads and tails.
- Show the total number of coin tosses.
